== Overview
This section clarifies who the ARINC 615A toolchain is intended for and the essential knowledge, network access, permissions, and media you should have in place before getting started.

=== Intended audience
- Avionics software and systems engineers integrating ARINC 615A-capable equipment
- Integration and test engineers performing lab or flight-line data loading
- Maintenance engineers/technicians operating the Data Loader
- Network administrators supporting ARINC 615A environments
- QA/compliance personnel verifying process adherence and traceability

=== Prerequisites
- Standards familiarity: basic understanding of ARINC 615A, ARINC 665 media sets, and ARINC 645 terminology
- Networking basics: IPv4 addressing/subnets, UDP, broadcast vs. unicast, firewalls/NAT, MTU/fragmentation
- OS permissions: awareness that privileged ports (<1024) on Unix-like systems typically require elevated privileges; Windows may require admin rights for some networking operations
- Access and environment: reachable Target Hardware on a network that allows required UDP ports (e.g., 1001 for FIND, 59 or dynamic ports for TFTP), and any site security approvals for data loading
- Media and data: ARINC 665 media sets and Load Upload Headers available for Upload operations and storage space for downloaded files

=== Precautions

Updating the software on an avionic device is dangerous and requires a high level of attention.
It should only be performed by qualified personnel in a safe environment.

Follow the avionic device manufacturer's instructions strictly!
Under no circumstances should you switch off the device during the update, as this may render it unusable.

== Download Operation

The ARINC 615A _Media Defined Download Operation_ and _Operator Defined Download Operation_ are used to download files from the Target Hardware to the Host Data Loader.
During the _Media Defined Download Operation_ the Host Data Loader transmits a predefined list of files to the target, whereas in the _Operator Defined Download Operation_ the Target Hardware first advertises a list of available files and the operator selects the files to be downloaded.
The Target Hardware itself transfers all necessary files to the host, and periodically provides an operation status.

|===

| Target IP Address | Destination address for the operation. | — | —

| TFTP Well-known Port | UDP port used for TFTP transfers. | 59 | <<arinc_615a_4>>, §5.3.2.3.2

|===

For further detailed information refer to <<arinc_615a_4>> Section 5.4.4.

[discrete]
=== ARINC 615A Checksum Option

When the Target Hardware Data Loader transmits the requested files, these files can be protected by an _ARINC 649 Check Value_.
The ARINC 615A Host Data Loader checks the file integrity when the check value is received.
If the integrity check fails, the operator is informed and the transmitted information must be considered as unreliable.

For further detailed information refer to <<arinc_615a_4>> Section 5.3.2.3.8.5.

[discrete]
=== ARINC 615A Part Number Option

The Target Hardware Data Loader can provide the _Part Number Option_ for the transmitted files.
The provided _Part Number_ is not evaluated in any kind but noted for the operator’s information.

NOTE: The transmission of the _Part Number Option_ is not defined for the Download Operations by the ARINC 615A standard.
The transmission of this option is an extension to the ARINC 615A standard.

For further detailed information refer to <<arinc_615a_4>> Section 5.3.2.3.8.4.

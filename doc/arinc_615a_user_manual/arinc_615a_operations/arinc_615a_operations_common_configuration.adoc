== Common Configuration Parameters

This section describes common parameters and important information, which are applicable to the:

- Information Operation,
- Upload Operation, and
- Media Defined/ Operator Defined Download Operation.

[discrete]
=== Summary of Common Configuration Parameters

[options="header"]
|===
| Parameter | Description | Default | Reference
| TFTP Well-known Port | UDP port where the Target Hardware Data Loader listens. Also used by the Host if the ARINC 615A Port Option is not used. | 59 | <<arinc_615a_4>>, §5.3.2.3.2
| TFTP Timeout | Maximum time between two consecutive TFTP packets before retry. | 2 seconds | <<arinc_615a_4>>, Att. 4.3.1; <<rfc_2349>>
| TFTP Retries | Number of retries when a TFTP packet is not received within the timeout. | 1 | <<arinc_615a_4>>, Att. 4.3.2
| TFTP Blocksize Option | Negotiates larger TFTP blocks to reduce transfer time. Falls back to default if unsupported. | negotiated | <<arinc_615a_4>>, §5.3.2.3.8.1; <<rfc_2348>>
| TFTP Transfer Size Option | Indicates total transfer size. Falls back to unknown if unsupported. | negotiated | <<arinc_615a_4>>, §5.3.2.3.8.2; <<rfc_2349>>
| TFTP Timeout Option | Negotiates TFTP timeout value. Falls back to default if unsupported. | negotiated | <<arinc_615a_4>>, §5.3.2.3.8.3; <<rfc_2349>>
| DLP Timeout | Maximum time between protocol files (e.g., status files) before terminating the operation. | 13 seconds | <<arinc_615a_4>>, Att. 4.4.1
| DLP Retries | Retries when a TFTP transfer fails during the DLP exchange before aborting the operation. | 1 | <<arinc_615a_4>>, Att. 4.4.2
| ARINC 615A Port Option | Host uses a dynamically selected local TFTP port to enable parallel loads and avoid privileged ports. | disabled | <<arinc_615a_4>>, §5.3.2.3.8.6
| Log Protocol Files | Store all received and transmitted ARINC 615A protocol files for analysis. | disabled | —
|===

[discrete]
=== Target ID
Refer to <<arinc_615a_4>> Section 5.3.4.

The _Target ID_ (called _Target Hardware Instance_ within the standard) identifies the concrete Target Hardware to perform ARINC 615A operations with.
It is composed of the _Target Hardware Identification_ and the _Position_, which
is obtained by the _FIND Operation_.

[discrete]
=== Target IP Address
The _Target IP Address_ is the address, where the ARINC 615A operation is issued
to.
This address and the _TFTP Well-known Port_ forms the ARINC 615A destination
information.

[discrete]
=== Source IP Address
The _Source IP Address_ is the source interface, where the requests are issued
from and the TFTP Server is bound to.
Normally, the source address is determined automatically when the target IP
address is selected.
It may be useful to define the address if more than one network interface is placed within the same network.

[discrete]
=== TFTP Well-known Port
Refer to <<arinc_615a_4>> Section 5.3.2.3.2.

The _TFTP Well-known Port_ is the UDP port, where the Target Hardware Data
Loader listens (by default the UDP port `59` is used).

NOTE: If the _ARINC 615A Port Option_ is not used, the Host Data Loader also uses this port for receiving TFTP requests from the Target Data Loader.

[discrete]
=== Default TFTP Timeout
Refer to <<arinc_615a_4>> Attachment 4.3.1 and <<rfc_2349>>.

The _TFTP Timeout_ is the maximum time between two consecutive TFTP packets.
If the time exceeds, the last TFTP packet transmitted is repeated.
If the number of _TFTP Retries_ has been reached, the TFTP transfer is aborted.
The default _TFTP Timeout_ is `2` seconds.

[discrete]
=== Default TFTP Retries
Refer to <<arinc_615a_4>> Attachment 4.3.2.

The _Number of TFTP Retries_ is the number of TFTP packet retries, when a packet is not received within the _TFTP Timeout_.
If the number of retries has exceeded, the TFTP transfer is aborted.
The default _Number of TFTP Retries_ is `1` retry.

[discrete]
=== TFTP Blocksize Option
Refer to <<arinc_615a_4>> Section 5.3.2.3.8.1 and <<rfc_2348>>.

The _TFTP Blocksize Option_ is used to increase the amount of data, which can be transferred during TFTP Operations.
The use of this option allows significantly decreasing data loading time.

NOTE: If the target hardware does not accept this option, the transfers are continued with the default TFTP blocksize.

See Also: <<tftp_blocksize_option>>

[discrete]
=== TFTP Transfer Size Option
Refer to <<arinc_615a_4>> Section 5.3.2.3.8.2 and <<rfc_2349>>.

The _TFTP Transfer Size Option_ is used to indicate the transfer size during
ARINC 615A Operations.

NOTE: If the target hardware does not accept this option, the transfers are continued without knowing the file sizes.

See Also: <<tftp_transfer_size_option>>

[discrete]
=== TFTP Timeout Option
Refer to <<arinc_615a_4>> Section 5.3.2.3.8.3 and <<rfc_2349>>.

The _TFTP Timeout Option_ is used to negotiate TFTP time out values between host
and target data loader.

NOTE: If the target hardware does not accept this option, the transfers are continued with the default TFTP timeout value.

See Also: <<tftp_timeout_option>>

[discrete]
=== ARINC 615A DLP Timeout
Refer to <<arinc_615a_4>> Attachment 4.4.1.

The _DLP Timeout_ is the maximum time between the transmission of two
subsequent protocol files (mostly status files).
If the timeout exceeds, the ARINC 615A operation is terminated.
The default _DLP Timeout_ is `13` seconds.

[discrete]
=== ARINC 615A DLP Retries
Refer to <<arinc_615a_4>> Attachment 4.4.2.

The _Number of DLP Retries_ is the number of TFTP operation retries, when a TFTP transfer fails.
If the number of retries has exceeded, the ARINC 615A operation is canceled with an abort.
The default _Number of DLP Retries_ is `1` retry.

[discrete]
=== ARINC 615A Port Option
Refer to <<arinc_615a_4>> Section 5.3.2.3.8.6.

If this option is set, the local TFTP server port is selected dynamically by the operating system and advertised to the Target Hardware Data Loader.
This option is used to allow independent parallel loading of multiple Target Hardware.
It also helps to lower privilege escalations of the application as no well-known ports need to be opened.

NOTE: If the Target Hardware does not support this option, the operation is canceled.
The operator needs to restart the operation without this option set.

Dynamic Port Option:: If this option is set, the Host Loader selects a dynamic port for TFTP Communication (Well-known-Port).
This option can be used when the OS denies the usage of privileged ports.
Parallel loading of multiple targets is implemented by using different ports for each target.

Log Protocol Files:: If this option is set, all received and transmitted ARINC 615A Protocol Files are stored for analysis.

[discrete]
=== Aborting ARINC 615A Operations
Refer to <<arinc_615a_4>> 5.3.2.3.6 and 5.3.2.3.7.

When the operator decides to abort an ARINC 615A Operation, this intent is transferred to the target hardware data loader.
This happens, when the Target Hardware Data Loader periodically sent the
operation status information.
The Target Hardware Data Loader will end the operation with a status information.
It depends on the Target Hardware Data Loader, how long it takes to abort the operation.

WARNING: When the operator decides to immediately abort the operation (e.g., by closing the application), the Target Hardware could be left in an undefined state.

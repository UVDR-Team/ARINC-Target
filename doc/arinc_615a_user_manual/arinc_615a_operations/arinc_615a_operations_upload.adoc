== Upload Operation

The ARINC 615A _Upload Operation_ is used to upload files (software, data, configuration, ...) from the Host Data Loader to the Target Hardware.
The operator selects the _ARINC 665 Loads_ (represented by a _Load Upload Header_ files).
The list is transmitted to the Target Hardware.
The Target Hardware itself requests all necessary files from the host, and periodically provides an operation status.

[discrete]
=== Parameters

[options="header"]
|===
| Parameter | Description | Default | Reference
| Target ID | Identifies the concrete hardware instance (from FIND). | — | <<arinc_615a_4>>, §5.3.4
| Target IP Address | Destination address for the operation. | — | —
| Source IP Address | Local interface used for requests and TFTP server binding. | auto | —
| TFTP Well-known Port | UDP port used for TFTP transfers. | 59 | <<arinc_615a_4>>, §5.3.2.3.2
| TFTP Options | Blocksize, Timeout, Transfer Size negotiation. | negotiated | <<arinc_615a_4>> §§5.3.2.3.8.1–3
| DLP Timeout / Retries | Max interval and retries for protocol/status files. | 13 s / 1 | <<arinc_615a_4>> Att. 4.4.1 / 4.4.2
| ARINC 615A Port Option | Use dynamic local TFTP port. | disabled | <<arinc_615a_4>> §5.3.2.3.8.6
| Part Number Option | Disambiguate files when multiple loads contain same filename. | optional | <<arinc_615a_4>> §5.3.2.3.8.4
| Checksum Option | Disambiguate files with identical names (not integrity). | optional | <<arinc_615a_4>> §5.3.2.3.8.5
|===

For further detailed information refer to <<arinc_615a_4>> Section 5.4.3.

[discrete]
=== ARINC 615A Part Number Option

When provided by the Target Hardware Data Loader, the _Part Number Option_ can be used to identify the load (by its _Load Part Number_) which contains the requested file.
This is necessary, when files with the same name are contained in multiple loads.

For further detailed information refer to <<arinc_615a_4>> Section 5.3.2.3.8.4.

[discrete]
=== ARINC 615A Checksum Option

When provided by the Target Hardware Data Loader, the _Checksum Option_ can be used to disambiguate a file when a media set contains multiple files with the same filename.
This option is not used to check the file integrity itself.

For further detailed information refer to <<arinc_615a_4>> Section 5.3.2.3.8.5.

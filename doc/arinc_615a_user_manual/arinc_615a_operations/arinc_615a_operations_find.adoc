== FIND Query
Refer to <<arinc_615a_4>> Attachment 3.

The _FIND Query_ is used to query all available _ARINC 615A_ targets within a network.
The reported IP Address and Target ID are used to initiate additional ARINC 615A Operations.

The FIND Client issues a so-called _FIND Information Request_ Packet to a destination address.
The FIND client waits for a defined timeout for answers of _FIND Targets_.
When the timeout exceeds all answers are presented to the operator.

Provided information are:

* Target Hardware Identifier,
* Target Type Name,
* Target Position,
* Literal Name, and
* Manufacturer Code.

[discrete]
=== Parameters

[options="header"]
|===
| Parameter | Description | Default | Reference
| Source IP Address | Local interface used to send the request. Auto-selected when Target IP is chosen. | auto | —
| Target IP Address | Destination address. Use broadcast to discover multiple targets, or unicast to query a known target. | — | —
| Target Port | UDP port used for FIND requests. | 1001 | —
| Dynamic Source Port Option | Select a source port dynamically to avoid privileged ports and simplify replies to sender. | disabled | —
| FIND Timeout | Time to wait for responses before listing results. | 3 seconds | —
|===

[discrete]
=== Source IP Address
The _Source IP Address_ is the source interface, where the request is issued from.
Normally, the source address is determined automatically when the target IP address is selected.
It may be useful to define the address if more than one network interface is placed within the same network.

[discrete]
=== Target IP Address
The _Target IP Address_ is the address, where the FIND request is issued to.
It could be a broadcast address of a network to address multiple ARINC 615A
targets or an unicast address to query a known target for information.

[discrete]
=== Target Port
The _Target Port_ is the UDP Port, where the FIND request is posted to.
By default, the UDP Port `1001` is used and can be overridden.

[discrete]
=== Dynamic Source Port Option
By default, the FIND request is issued from the _Local IP Address_ and
_Target Port_ (by default `1001`).
If this option is set, the source port is selected dynamically by the operating system.
If the FIND Request is answered by the target directly to the sender of the
request, the concrete source port is not needed to be pre-defined.
This option helps to lower privilege escalations of the application as no
well-known ports need to be opened.

[discrete]
=== FIND Timeout
The FIND timeout is the time, the FIND Client waits for responses of ARINC 615A targets.
By default, the timeout is set to `3` seconds.

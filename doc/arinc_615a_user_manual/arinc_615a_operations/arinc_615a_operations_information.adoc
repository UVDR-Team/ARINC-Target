== Information Operation
The ARINC 615A _Information Operation_ is used to query information on the configuration of the Target Hardware.
When the operation is requested by the operator and acknowledged by the target hardware, the so called _Load Configuration List_ is transferred from the target hardware to the host.
It contains a list hardware with:

* *Literal Name*,
* *Serial Number*, and
* a list of *Part Number* information.

Per *Part Number* information:

* the *Part Number* itself,
* *Amendment* information, and
* a *Part Designation* is contained.

=== ARINC 615A Checksum Option (for Load Configuration List)

When the Target Hardware Data Loader transmits the _Load Configuration List_, this file can be protected by an _ARINC 649 Check Value_.
The ARINC 615A Host Data Loader checks the file integrity when the check value is received.
If the integrity check fails, the operator is informed and the transmitted information must be considered as unreliable.

For further detailed information refer to <<arinc_615a_4>> Section 5.3.2.3.8.5.

== Troubleshooting

=== No FIND responses
- Ensure the Target and Host are on the same subnet or that routing/broadcast is permitted.
- Try unicast FIND to a known Target IP if broadcast is filtered.
- Verify firewall rules allow UDP 1001 and ephemeral source ports.

=== TFTP timeouts or slow transfers
- Increase TFTP Timeout and/or Retries in Common Configuration.
- Enable Blocksize Option to reduce overhead; ensure MTU is sufficient to avoid fragmentation.
- Check for packet loss on the network and duplex/MTU misconfiguration.

=== Port conflicts or permission errors
- If binding to UDP 59 fails due to privileges, enable the ARINC 615A Port Option to use a dynamic local port.
- Ensure firewalls allow inbound UDP on the selected port(s).

=== Checksum mismatch (Download or Information)
- Treat received data as unreliable; retry the operation.
- Verify media integrity and network stability; avoid intermittent links during transfer.

=== Parallel loads to multiple targets
- Enable the ARINC 615A Port Option so each operation can use a separate dynamic port.
- Stagger start times slightly if the host or network is resource constrained.

=== Aborting operations
- Prefer a graceful abort via the application UI/CLI so the target can terminate cleanly.
- Avoid force-closing the application; if it happens, consult target procedures to verify and recover its state.

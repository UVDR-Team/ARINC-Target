NATIVE WORKBENCH MANAGED PROJECT: VxWorks Downloadable Kernel Module (DKM)
Platform/VSB/BSP/CPU/ABI: select the SAME ones used to build the office target image.

Compile ONLY .cpp files listed in SOURCES.txt (all are under src/).
Do not compile include/, tests/, or the top-level workbench/ folder.
No main.cpp; no external third-party archives; no Git or CMake generation needed.

C++ compiler settings (keep Workbench-generated CPU/ABI/DKM settings):
  -std=c++20
  -g
  -O0
  -fexceptions
  -frtti
  -include arinc_support/BuildConfig.hpp

Project-relative include search directories (use absolute paths if UI requires):
  include
  src/lib
  src/workbench
  src/app/arinc_615a_unit_test/arinc_615a_test_tha

Use the normal Workbench DKM C++ linker/constructor processing.
Do not replace it with a raw ld -r link. Do not use host-built .a files.
Do not add Boost, Helper, Qt, ARINC 645 or ARINC 649 libraries.

Entry points:
  int arinc615aSelfTest(void);             quick codec/hash diagnostic
  int arinc615aDemo(void);                 blocking FIND + Information demo
  int arinc615aRun(const char *filename);  blocking configured loader
  int arinc615aStop(void);                request stop from another task

Runtime: VxWorks C++20 standard library including format, chrono formatting,
filesystem, ranges, span, exceptions, RTTI, atomics, mutexes and threads;
POSIX pthreads/semaphores, time services, select, IPv4 UDP sockets and network;
mounted writable filesystem for uploads; readable source files for downloads.
Component names vary by the installed VxWorks platform: use its component catalog.
These SDK/image capabilities cannot be supplied by this open-source folder.

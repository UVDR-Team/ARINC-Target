# ARINC 615A Example Target Hardware Application {#arinc_615a_test_tha_main}

This Test *Target Hardware Dataloader* provides following operations:
 - FIND Operation,
 - Information Operation,
 - Upload Operation,
 - Media Defined Download Operation, and
 - Operator Defined Download Operation.

The application is configurable via a JSON file.

## FIND Operation
The FIND Server listens on the IP address and UDP port specified within the application configuration.
The advertised FIND information is also set within the application configuration.
